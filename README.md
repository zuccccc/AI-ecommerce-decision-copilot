AI-Powered E-Commerce Decision Copilot

This project is an AI-powered Streamlit dashboard for analysing e-commerce return behaviour, customer segments, product categories, payment methods, and business recommendations.

Features

Interactive business dashboard with return KPIs
Product category return analysis
Customer segmentation by rating and payment method
AI copilot powered by OpenRouter API
Natural-language business question answering
Dataset summary generation from filtered data
Tech Stack

Python
Streamlit
Pandas
Plotly
OpenRouter API
How the AI Copilot Works The app reads a cleaned e-commerce CSV file, applies user-selected filters, generates a compact dataset summary, and sends that summary to the AI copilot. The AI then provides business-friendly insights and recommendations.
